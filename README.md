🚗 Automotive Market Analytics Dashboard
📌 Project Overview

This project presents an interactive Power BI dashboard designed to analyze automotive market data and identify patterns affecting vehicle pricing, mileage, and performance.

The solution helps users explore relationships between car characteristics such as brand, fuel type, engine size, model year, and number of doors.

🎯 Business Objectives
Analyze vehicle pricing trends.
Compare performance across different brands.
Examine fuel type distribution.
Evaluate mileage patterns.
Study horsepower differences.
Identify factors influencing vehicle value.
